隐私政策 (Privacy Policy)

生效日期：2026年9月1日 | 最近更新：2026年9月19日

PhraseEcho 是一款坚守“离线优先 (Offline-First)”理念的应用。我们高度尊重并保护用户的个人隐私，核心业务流程不依赖网络，不追踪、不出售您的任何数据。

1. 数据的本地存储与处理

PhraseEcho 遵循数据最小化与本地化原则：

  • 学习数据与记录：您在应用内创建或导入的所有短语、单词、笔记、录音文件、复习进度以及统计日志，均仅存储在您设备的本地数据库（如 SQLite/Room）和应用沙盒中。
  • 无云端同步与分析：PhraseEcho 未部署任何用户行为埋点（Analytics）、日志上传或第三方追踪 SDK。

2. 设备权限调用说明

为向您提供必要的语言训练功能，PhraseEcho 可能申请以下权限，每项权限均仅在对应功能触发时在本地使用：

  • 麦克风权限 (Microphone)：用于录制您的发音片段或练习短语。录音数据仅保存在您的设备本地，供您个人回听与对照，绝不上传到任何远程服务器。
  • 语音识别权限 (Speech Recognition)：用于将您说出的练习语句转换为文本。优先使用系统本地语音引擎；我们不会将您的语音用于算法训练或二次转录分析。
  • 存储 / 文件访问权限：仅当您主动触发“导出备份 (JSON/CSV)”或“从文件恢复”功能时，应用会请求访问您指定的保存路径。

3. 可选网络功能与第三方 API 密钥

应用的核心词库维护、音频播放与自适应复习功能 100% 离线可用。若您选择配置并启用扩展的第三方翻译或大模型润色服务：

  • API Key 的安全保护：您输入的个人 API Key（例如 OpenRouter 等）仅存储在系统的安全硬件模块中（如 Android EncryptedSharedPreferences / Keychain），不会被明文保存或上传至我们的服务器。
  • 请求发送：网络请求仅直接发送至您所选定的服务提供商接口，请求内容仅包含当前待翻译或解析的单句文本。

4. 数据导出、备份与删除

您对自己的数据拥有绝对的控制权：

  • 您可以随时使用应用内的导出功能，将所有学习数据以开放标准的 JSON 或 CSV 格式导出到本地文件或转移至其他平台。
  • 您可以随时清空学习库，或直接卸载应用。卸载后，存储在应用私有沙盒中的所有数据将被系统彻底删除。

5. 隐私政策的更新

若应用增加重大功能或适配相关法律法规变更，我们将通过此网页更新隐私政策。建议您定期查阅以了解最新内容。
