隐私政策 (Privacy Policy)

生效日期：2026年9月19日 | 最近更新：2026年9月19日

PhraseEcho 是一款本地优先 (Local-First)的语言学习应用。核心学习、播放和复习流程主要在设备上完成；某些可选功能会在用户主动使用时访问 Apple、iCloud 或 OpenRouter 等第三方服务。

1. 本地数据

PhraseEcho 遵循数据最小化与本地优先原则：

  • 学习数据与记录：您在应用内创建或导入的短语、单词、笔记、复习进度和统计记录默认存储在设备本地。
  • 原始麦克风录音：当前 iOS 版本使用麦克风输入进行语音识别，不将原始麦克风录音作为学习记录长期保存。
  • 开发者服务：PhraseEcho 不运营用户账户、广告、行为分析或自己的学习数据上传服务器。

2. 麦克风与语音识别

为完成语音录入，PhraseEcho 会在用户主动开始录音识别时申请麦克风和语音识别权限。

  • 设备端识别：在系统支持且资源可用时，语音可以在设备上处理。
  • 系统语音服务：在设备端识别不可用时，Apple 的系统语音识别服务可能处理音频。该处理受 Apple 自己的隐私政策约束。
  • 文件访问：导入或导出文件时，PhraseEcho 仅访问用户通过系统文件选择器明确选择的文件或保存位置。

3. iCloud 备份

如果用户已登录 iCloud 且系统允许 PhraseEcho 使用 iCloud Drive，iOS 版本可能在学习数据变化后自动保存完整 JSON 备份。

  • 备份保存在用户自己的 iCloud Drive 中，由 Apple 的 iCloud 服务存储和同步。
  • PhraseEcho 开发者不运营该云端存储，也无法直接读取用户的 iCloud 文件。
  • 用户可以在应用内或 iCloud Drive 中管理、恢复和删除这些备份。

4. 可选 OpenRouter AI 翻译功能

PhraseEcho 的可选 AI 辅助翻译完全由用户主动触发，不影响核心离线学习与复习流程。

  • 当用户主动使用 AI 翻译时，待翻译的短句原文与目标语言设置会发送至 OpenRouter，由用户指定的模型服务提供商处理并返回译文。
  • PhraseEcho 不通过自己的服务器转发这些请求，也不会将用户的 OpenRouter API Key 上传给 PhraseEcho。API Key 使用设备系统提供的安全存储机制保存。
  • OpenRouter 及实际模型供应商的数据保留、训练和处理方式以其最新政策为准，请勿提交密码、私人对话或其他敏感内容。请参阅 OpenRouter 隐私政策。

5. 导出、删除与保留

  • 您可以使用 JSON 完整备份或 CSV 导入导出功能管理自己的学习数据。
  • 卸载 App 会清除应用内部沙盒中的数据库与缓存；但您主动导出保存在本机文件系统中的备份文件（以及同步至 iCloud Drive 的备份）均不会被删除。未来重新安装 App 后，您可以随时重新导入这些文件恢复学习数据。
  • PhraseEcho 不在自己的服务器上保存用户学习数据。第三方服务的数据保留和删除规则由对应服务商负责。

6. 支持来信与沟通

如果您通过官方支持邮箱联系我们，您的邮箱地址、邮件正文以及您选择提供的排查信息将仅用于解答您的问题和协助故障排除。

  • 请不要在来信中附带密码、OpenRouter API Key、完整备份文件内容或其他高度敏感信息。
  • 支持往来邮件仅在处理您的咨询或排查问题所需的必要时间内保留，并将在您提出申请后予以删除。

7. 政策更新与联系我们

如果功能、第三方服务或适用法律发生重大变化，我们会在此页面更新政策和日期。
